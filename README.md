This repository contains a collection of beginner-friendly web development projects created while learning HTML and CSS.

The projects demonstrate the use of basic HTML tags, forms, tables, lists, links, images, CSS styling, and simple webpage layouts.

Projects

1. Personal Portfolio Website
 A simple personal portfolio website created using HTML and CSS.

2. Basic HTML Tags
A simple webpage created to practice and demonstrate the basic HTML tags and elements.

3. HTML Login Page
A simple login page created to practice HTML forms and form elements.

4. CS Department Website
A simple Computer Science Department website created to practice HTML page structure
